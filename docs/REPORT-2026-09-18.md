# Report — 2026-09-18

## Goal

Build a reliable Qwen 3.8 local-agent template for OMP development, with llama.cpp and NInfer support, giant-context operation, less runaway XHIGH thinking, better tool-loop behavior, and deliberate context hygiene.

## What we established

### Froggeric v22.5

- Defaults Qwen 3.8 to MEDIUM instead of official XHIGH.
- Preserves historical thinking by default.
- Supports original sticky inline `<|think_*|>` controls.
- Repairs tool-call rendering, tool-error recovery, empty-think/history issues, and prefix-cache stability.
- Upstream has a substantial test suite and deterministic fuzzer; we retain them rather than starting over.
- Current Frog logic scans retained system/developer/user history so a later tagged message overrides earlier ones, but within one message its old controls are selected by an `if/elif` priority rather than true textual order.

### Reasoning controls

Target surface:
- **LOW** — Qwen native low.
- **MEDIUM** — Qwen native medium, default.
- **high** — our iterative agent workflow, not a new trained Qwen level.
- **XHIGH** — Qwen native xhigh.
- off stays available as `<[/]>` / `<[off]>` for automation/workflows.

Custom high is intentionally action-biased: if a read/search/test/tool can resolve uncertainty, obtain the evidence instead of spending thousands more tokens predicting it.

### Why preserve_thinking matters

Preserved reasoning lets successive tool-loop turns continue from prior hypotheses and decisions instead of re-deriving them. This makes the desired high behavior closer to several connected MEDIUM-sized reasoning passes than one huge XHIGH monologue.

### What the template cannot do alone

Jinja renders before generation. It cannot:
- observe that 75% of a reasoning budget was consumed;
- inject a warning mid-generation;
- create extra hidden model turns by itself;
- invoke OMP slash commands directly unless OMP exposes an appropriate controller/tool path.

Those belong in the runtime or OMP controller.

### OMP already has the context primitives we wanted

Current OMP has:
- **Shake**: local mechanical elision of heavy tool results and large fenced/XML blocks into recoverable `artifact://` references.
- manual modes `/shake`, `/shake images`, `/shake thinking`;
- auto-shake configuration that protects a recent tail and requires useful savings;
- pre-compaction pruning and useless-result elision;
- experimental **notes-backed context windows** with `context_notes`, `new_context`, and full history recovery via `read` / `grep` on `history://current/full`.

That means we do not need to invent a second transcript database just to make old work searchable.

## Context-memory direction

Use the OMP session journal as source of truth.

Keep a small working-state ledger in `context_notes`: current objective, confirmed facts, active hypotheses, decisions, changed files, pending tests, and history entry IDs when useful.

At safe tool-loop boundaries:
1. consume tool output;
2. record durable conclusions, not raw output;
3. let Shake/pruning offload bulky recoverable history;
4. continue using preserved recent reasoning;
5. use `new_context` when a context-window rollover is actually needed;
6. recover details later with grep/read against `history://current/full`.

This is cheaper and more robust than permanently carrying old tool transcripts.

## Optional graph layer

If a graph proves useful later, make it an index over OMP history, not another source of truth. Proposed compact text format:

```text
N\t42\tdecision\tactive\tUse q8_0/q4_1 KV for long-context test\trefs=H183,H191
N\t43\tfile\tactive\tparser.ts changed for retry guard\trefs=H204
E\t43\tdepends_on\t42
```

TSV is grep-friendly, cheap in tokens, diffable, and trivial for an LLM or script to parse. Raw evidence stays in OMP history/artifacts. Codex-Timelines can later import/export this index if useful.

## Reliability rule

No behavioral change is accepted until the old Frog tests and new extension tests pass. Engine-specific behavior is separately smoke-tested rather than inferred from Jinja rendering alone.
